Motion machine

MM is the magic. It has a job, or it does not ship.

Live in this file

Six rules. That is the whole machine.

If a motion does not make the next action clearer, cheaper, or kinder, delete it. Reduced-motion users get the same information without the orbit.

01

Spring

Overshoot once, settle. Buttons lift 2px, cards 6px. No bounce loops.

02

Scroll timelines

Progress and reveals ride the scroll, not a timer. If animation-timeline is missing, they stay visible.

03

Haptic press

Gold buttons track the pointer a few pixels, then snap home. Coarse pointers skip the ring.

04

INP first

No motion work on the first input frame. Transforms and opacity only. No layout thrash.

05

Reduced motion

prefers-reduced-motion kills orbits, blurs, and title rises. Content never depends on the animation finishing.

06

Pointer honesty

Fine pointer gets the ring. Touch does not get a fake cursor. Hover is never the only path.
